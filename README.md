# IRON SIEGE

A fast, dependency-free top-down tank arena shooter. You are the last operational tank in Sector 07. Hostile armor arrives in escalating waves — outmaneuver them, use cover, shoot the barrels, and stay alive.

## Play

Open `index.html` through any static web server, or run the project's `start.sh`. It is a pure HTML/CSS/Canvas game with no build step and no third-party runtime dependencies.

## Controls

| Action | Desktop | Mobile |
| --- | --- | --- |
| Move | `WASD` / arrow keys | Left thumb stick |
| Aim | Mouse | Right thumb stick |
| Fire | Left click / `Space` | Right stick (auto-fire) |
| Pause | `P` / `Esc` | Pause button |
| Restart | `R` (after destruction) | Play Again button |

## Features

- Three hostile AI tank classes with pursuit, strafing, line-of-sight, and obstacle avoidance.
- Wave progression with escalating armor, damage, and heavy-tank frequency.
- Destructible crates, explosive fuel barrels, rocks, and concrete cover.
- Repair, shield, and overdrive pickups with magnetic pickup radius.
- Persistent high score, kill feed, radar, minimap viewport, off-screen threat arrows.
- Procedurally painted battlefield, persistent tread marks, particles, screen shake, and synthesized WebAudio effects.
- Responsive HUD, touch controls, safe-area insets, and portrait/landscape phone support.
